Forkarak **1.0.9**에서는 Git 화면과 코드 화면의 사이드바에서 브랜치를 바로 푸시하거나 삭제할 수 있습니다. **로컬 브랜치** 목록에서 이름 옆의 **…**를 누르거나 브랜치를 우클릭해 보세요.

- **Push…**를 누르면 선택한 브랜치가 ‘보낼 브랜치’에 입력됩니다. 받을 원격 저장소와 브랜치를 확인하거나 바꾼 뒤 미리보기에서 푸시할 수 있습니다.
- **로컬 브랜치 삭제…**를 누르면 삭제할 브랜치와 커밋이 표시됩니다. Git의 병합 검사를 통과한 로컬 브랜치만 삭제하며, 현재 또는 다른 워크트리에서 사용 중인 브랜치는 메뉴에 이유가 표시됩니다.
