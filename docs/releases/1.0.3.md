Forkarak **1.0.3**에서는 GitHub API가 HTTP 403을 반환해 Kotlin 언어 서버 설치가 중단되던 문제를 수정했습니다. Apple Silicon Mac, macOS 13 이상을 지원합니다.

Kotlin 서버 버전은 JetBrains의 공식 릴리스 목록에서, 함께 설치하는 Temurin JDK 버전은 Adoptium에서 조회합니다. 처음 설치하거나 업데이트할 때 GitHub 토큰을 입력할 필요가 없습니다. 설치를 마치기 전에 Kotlin 서버, JDK, Maven 다운로드의 체크섬을 확인합니다.

### 이전에 403 오류가 발생했다면

1. **설정 → 업데이트 확인**에서 Forkarak을 1.0.3으로 업데이트하고 재시작하세요. CLI를 사용하는 경우 앱을 종료한 뒤 `forkarak update`를 실행하세요.
2. **설정 → 언어 분석·포맷 → 설치·업데이트 관리…**에서 **JetBrains Kotlin LSP → 다시 시도**를 누르세요. 처음 설치한다면 **설치**를 누르세요.
