Forkarak **1.0.2**는 Kotlin 도구 설치 오류를 진단하기 쉽게 하고, 여러 창에서 작업할 때 초안과 Git 변경을 더 정확하게 표시합니다. Apple Silicon Mac, macOS 13 이상을 지원합니다.

### 언어 도구

- Kotlin LSP 설치 중 다운로드가 실패하면 어느 구성 요소를 받던 중이었는지, 실패한 단계와 호스트, HTTP 상태를 한 번만 표시합니다. 상세 진단을 복사하거나 같은 화면에서 다시 시도할 수 있습니다. 이전 버전에 기록된 403 오류도 확인할 수 있습니다.

### 편집과 탐색

- 여러 창에서 같은 파일을 편집할 때 서로 다른 미저장 초안을 복구할 수 있습니다. 편집기에서 파일을 저장했는지와 Git에 변경이 남아 있는지도 구분해 표시합니다.
- 프로젝트 검색에서 같은 줄에 반복되는 단어를 각각 정확한 위치에 강조합니다. 작업 로그의 상대 경로를 누르면 그 작업을 실행한 디렉터리 기준으로 소스 파일을 엽니다.
- 읽기 권한이 없는 경로가 있어도 조회 가능한 파일과 검색 결과를 보여 주고, 누락된 경로가 있음을 알립니다.

### Git 변경 검토

- 변경 통계를 한꺼번에 구하고 파일을 선택할 때 diff를 불러와, 변경 파일이 많은 워크트리의 목록을 더 빠르게 열 수 있습니다.
- Git의 줄바꿈 규칙을 비교에 반영하고, 내용이 같아도 실행 권한이 바뀌면 파일 모드 차이를 표시합니다.
- 그래프에서는 현재 체크아웃한 브랜치를 먼저 표시합니다. 좁은 창에서도 상태 표시줄에서 현재 워크트리와 비교 기준을 확인하기 쉬워졌습니다.

### 설치와 업데이트

기존 사용자는 **설정 → 업데이트 확인**을 누르거나 앱을 종료한 뒤 `forkarak update`를 실행하세요. [Apple Silicon용 앱 다운로드](https://github.com/dave915/Forkarak/releases/download/v1.0.2/Forkarak-macos-arm64.zip) · [설치 및 CLI 안내](https://github.com/dave915/Forkarak/blob/v1.0.2/docs/distribution.md)

배포 앱은 ad-hoc 서명됩니다. Apple 공증을 받지 않아 처음 열 때 macOS 보안 경고가 표시될 수 있습니다.
