Forkarak **1.0.6**에서는 여러 파일에 걸친 심볼 이름 변경을 초안으로 검토하고, 편집기에서 테스트를 실행해 실패한 줄로 이동할 수 있습니다. Apple Silicon Mac과 macOS 13 이상을 대상으로 합니다.

### 이름 바꾸기와 빠른 수정

- 워크트리에서 언어 분석을 켜면 **이름 바꾸기**로 심볼과 그 사용처를 함께 바꾸거나 **빠른 수정**으로 커서 위치에 제안된 수정을 선택할 수 있습니다. 다른 파일까지 바뀔 때는 파일별로 수정할 줄을 먼저 확인합니다.
- 변경은 열지 않은 파일까지 포함해 초안에 한 번에 적용됩니다. **되돌리기**로 취소하거나 **모두 저장**으로 디스크에 반영할 수 있습니다. 저장에 실패한 파일은 원인을 확인할 수 있고 초안도 유지됩니다.

### 테스트 실행과 실패 위치

- 실행을 허용한 워크트리에서는 커서 위치의 테스트나 현재 파일의 테스트를 실행하고 마지막 테스트를 다시 실행할 수 있습니다. Gradle·Maven의 JUnit 테스트와 Rust의 Cargo 테스트를 인식하며, JUnit Jupiter의 반복 테스트도 커서 위치에서 실행할 수 있습니다. npm 프로젝트에서는 현재 파일 경로를 `npm test`에 전달합니다.
- 미저장 초안이 있으면 모두 저장한 뒤 실행하거나 디스크에 있는 버전으로 실행할 수 있습니다. 하단의 테스트 결과에서 로그를 확인하세요. Gradle·Maven이 이번 실행의 JUnit 보고서를 남기면 실패 목록에서 해당 워크트리의 소스 줄로 이동할 수 있습니다.

### 분할 편집기와 단축키

- **편집기 오른쪽으로 분할**로 현재 파일을 양쪽에 띄우거나, 다른 파일을 **옆에 열기**로 나란히 볼 수 있습니다. 양쪽은 탭과 커서 위치, 탐색 기록을 따로 기억하고 같은 파일의 초안은 공유합니다. 미리보기 탭을 사용하면 양쪽에서 각각 한 탭을 재사용하며, 편집하거나 고정한 탭은 그대로 남습니다.
- 설정에서 Forkarak, IntelliJ, VS Code의 macOS 단축키 프리셋을 선택할 수 있습니다. 직접 지정한 단축키는 프리셋을 바꿔도 유지되며, 프로젝트별 단축키가 전역 설정보다 우선합니다. 보조 키만 표시할 때도 ⌘, ⌥ 같은 macOS 기호를 사용합니다.

### 변경 검토와 Git 동기화

- 파일 트리의 폴더 펼치기·접기 버튼을 검색창 옆으로 옮겼습니다. 변경 파일 목록 상단의 검토 메뉴에서 **미검토만** 또는 **다음 미검토**를 선택할 수 있습니다. diff의 단어 강조는 삭제 줄과 추가 줄이 서로 대응할 때만 표시됩니다.
- Git 도구 막대의 Pull과 Push가 현재 브랜치의 업스트림을 따릅니다. 업스트림이 없는 브랜치는 **게시**로 처음 푸시하고 추적 대상을 설정할 수 있습니다.
