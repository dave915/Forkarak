Forkarak **1.0.7**에서는 제목 막대와 Git·파일 도구 막대의 버튼을 더 작게 정돈했습니다. Apple Silicon Mac과 macOS 13 이상을 대상으로 합니다.

- 앱 화면을 확대하거나 축소하면 도구 막대 아이콘, 탭 닫기 버튼의 × 표시, 저장·새로고침 중에 보이는 아이콘도 함께 커지거나 작아집니다.
- Git 도구 막대는 긴 브랜치 이름을 한 줄로 줄여 표시합니다. 이름 위에 포인터를 올리면 전체 이름을 확인할 수 있습니다.
- 편집기를 둘로 나누면 **저장**과 **코드 지원…** 버튼이 각 편집기 너비에 맞춰 아이콘만 표시하거나 이름을 함께 표시합니다. 공간이 충분하면 **명령** 버튼으로 명령 팔레트를 열 수 있습니다.
