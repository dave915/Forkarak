# VSCode Icons

The file icons are original, unmodified SVGs from the [VSCode Icons 13.0.0 release](https://github.com/vscode-icons/vscode-icons/releases/tag/v13.0.0) by Roberto Huertas and the vscode-icons contributors. The project distributes its icons under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). Branded artwork is subject to its respective owner's copyright license. Upstream code and theme data carry the accompanying MIT license in LICENSE.txt.

Pokarak adapts the release's filename, suffix and light-theme associations for its native file lists. The file artwork retains the original colors. To reproduce the import, run `python3 scripts/import-vscode-file-icons.py /path/to/vscode-icons-13.0.0.vsix` with the official GitHub release asset.
