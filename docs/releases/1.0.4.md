Forkarak **1.0.4**에서는 브랜치를 더블클릭해 체크아웃할 수 있고, 코드를 입력하는 위치에서 자동완성과 함수 도움말을 볼 수 있습니다. Apple Silicon Mac, macOS 13 이상을 지원합니다.

### Git

- 사이드바나 커밋 그래프에서 전환할 로컬 브랜치를 더블클릭하면 현재 브랜치와 전환할 브랜치가 표시됩니다. **체크아웃**을 누르면 전환하고, 한 번 클릭하면 해당 커밋을 엽니다.
- Push와 Merge 확인창에서 브랜치와 워크트리를 먼저 확인하고, 필요할 때 커밋·파일 상세를 펼칠 수 있습니다.

### 편집기

- **설정 → 언어 분석·포맷 → 언어 서버 선택·설치…**에서 서버를 선택하고 워크트리 분석을 허용하세요. JSON을 직접 작성할 필요가 없습니다. 서버가 지원하면 입력 중 커서에 자동완성 후보가 나타납니다. **⌃Space**로 직접 열거나 **⌘I**로 함수의 현재 인자를 확인할 수도 있습니다.
- **F12**로 정의가 하나인 심볼의 소스로 이동하고, **⌥⇧F12**로 사용처를 파일별 코드 문맥과 함께 편집기 탭에서 확인할 수 있습니다. 기존 팝오버도 탐색 설정에서 선택할 수 있습니다.
- **⌘+**와 **⌘−**로 화면 배율을 5%포인트씩 조절할 수 있습니다.

### 업데이트

기존 설치에서는 **설정 → 업데이트 확인**을 사용하세요. CLI에서는 앱을 종료한 뒤 `forkarak update`를 실행하세요.
