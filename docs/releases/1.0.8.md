Forkarak **1.0.8**에서는 정의나 참조 찾기 요청이 취소돼도 다음 조회에 정상 동작 중인 언어 서버를 그대로 사용합니다. Apple Silicon Mac과 macOS 13 이상을 대상으로 합니다.

- 응답 대기 시간이 초과되거나 편집으로 인해 요청을 보낼 때의 코드가 더 이상 최신 상태가 아니면 해당 요청만 취소합니다.
- 취소한 요청의 응답이 뒤늦게 도착하면 요청 ID를 확인해 무시합니다.
