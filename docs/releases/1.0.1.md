Forkarak **1.0.1**은 편집·코드 탐색과 Git 그래프의 읽기 흐름을 다듬은 업데이트입니다. Apple Silicon Mac, macOS 13 이상이 대상입니다.

### 변경 사항

- 커밋 표시를 속이 빈 원으로 통일하고, 밝은 테마의 브랜치 색과 경로 구분을 개선했습니다.
- 자동 갱신 중 표시하던 코드·diff와 분할 미리보기의 읽던 위치를 유지하고, 불필요한 갱신 표시를 줄였습니다.
- Java 심볼을 ⌘ 클릭하면 정의로 이동하면서 사용처도 확인할 수 있습니다. 명시적으로 분석을 허용한 뒤 원래 탐색 요청을 이어갑니다.
- 작업 파일을 열자마자 편집할 수 있으며, 원래 내용으로 되돌리면 미저장 표시가 바로 해제됩니다. 저장과 Stage·커밋은 별도 동작입니다.
- 단축키 안내를 개별 키캡으로 표시해 조합을 읽기 쉽게 했습니다.
- 그래프 상단의 중복 행을 줄이고 비교 기준은 상태 표시줄에 유지했습니다. 대화상자·선택 행의 왼쪽 정렬과 편집기 팝오버의 스크롤 범위를 정리했습니다.

### 설치와 업데이트

기존 사용자는 앱의 **설정 → 업데이트 확인** 또는 앱을 종료한 뒤 `forkarak update`로 업데이트할 수 있습니다. 새 설치는 [앱 다운로드](https://github.com/dave915/Forkarak/releases/latest/download/Forkarak-macos-arm64.zip)나 [설치·CLI 안내](https://github.com/dave915/Forkarak/blob/v1.0.1/docs/distribution.md)를 이용하세요.

번들은 ad-hoc 서명이며 Apple Developer ID 공증은 없습니다. 다운로드한 앱에 macOS 보안 경고가 표시될 수 있습니다. 언어 분석은 명시적 허용이 필요하며, 의미 기반 결과와 텍스트 후보를 구분합니다.
