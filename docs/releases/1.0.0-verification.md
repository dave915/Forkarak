## 기존 실제 앱 검증과 구분

같은 기능 소스로 프로젝트 8개를 연 1440×900 창에서 상단 탭 드래그, 목록의 끝→처음 및 처음→끝 이동, 두 표면의 동일한 저장 순서를 확인했다. 순서 변경 중 활성 프로젝트와 `src/main.rs`는 유지됐다. 940×580 재시작에서 순서·활성 프로젝트를 복원하고, 목록의 숨겨진 프로젝트 선택과 해당 탭 자동 표시도 확인했다. 저장소 8개는 그대로였고 분석 허용 목록은 비어 있었다.

대표적인 편집·Git·터미널·언어 관리·CLI 흐름의 이전 검증과 이번 코드 검토는 별도 증거다. 전체 개선 목록의 모든 조합을 실제 GUI로 반복 검증했다는 뜻은 아니다. 드래그 가장자리 정지 스크롤·Escape의 별도 실제 조작 녹화는 이번에 추가하지 않았으며, 관련 로직은 단위 테스트·소스 검토 범위다.

## 공개 전후 검증

태그 워크플로는 macOS 15에서 포맷·Clippy·설치/CLI/리소스/앱 테스트, release 빌드·패키징, 실제 Java 설치·이동 검증을 통과한 뒤에만 공개한다. 공개 뒤에는 릴리스 자산·태그 커밋·체크섬과 익명 다운로드/격리 HOME 설치를 별도로 확인한다. 이 문서는 아직 수행하지 않은 원격 CI나 공개 다운로드를 통과했다고 미리 표시하지 않는다.

Apple Silicon/macOS 13 이상이 배포 대상이다. macOS 13 실기기와 Intel/Windows/Linux 배포, Apple Developer ID 공증은 검증하지 않았다. 현재 번들은 ad-hoc 서명이다.
