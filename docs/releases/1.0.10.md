Forkarak **1.0.10**에서는 사이드바의 체크아웃 표시, 브랜치 푸시, Git 그래프 열 크기 조정을 개선했습니다.

- **체크아웃 표시** — 여러 브랜치가 같은 커밋을 가리켜도 현재 워크트리에서 체크아웃한 브랜치에만 체크 표시가 나타납니다.
- **브랜치 푸시** — 사이드바에서 푸시를 열면 선택한 브랜치에 설정된 업스트림이 기본 대상으로 표시됩니다. 로컬과 원격 브랜치의 이름이 다른 경우에도 해당 원격 브랜치를 사용합니다.
- **브랜치 이름 변경** — 다른 워크트리에서 사용 중인 브랜치는 메뉴에서 이름을 변경할 수 없는 이유를 표시합니다.
- **Git 그래프** — 열을 좁혀도 선 간격이 유지되며, 열 밖으로 넘친 부분은 가려집니다.
