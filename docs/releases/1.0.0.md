Forkarak **1.0.0**은 코드를 읽고 편집하고, Git 변경을 검토·커밋하며 워크트리를 오가는 Apple Silicon Mac용 네이티브 작업 공간입니다. macOS 13 이상이 필요합니다.

### 주요 기능

- 프로젝트 탭·전체 프로젝트 목록의 드래그 순서 변경과 재시작 복원, 워크트리별 파일·초안·검색·읽던 위치 유지
- 한 줄 도구 모음, 파일 트리와 탭, 빠른 파일 열기·검색·명령 팔레트, 명시적 편집·저장과 외부 변경 조정
- 커밋 그래프, 통합·좌우 diff, 변경 단어 강조와 검토 표시, 파일·블록·줄 스테이징, 브랜치·원격·Stash·충돌 해결
- 워크트리별 터미널과 작업 실행·로그, Claude/Codex CLI 실행 설정과 Spring 작업 확장
- 관리형 언어 도구와 명시적 분석 허용. Java 서버·Temurin 런타임은 번들에 포함하며 추가 도구는 앱에서 설치
- 새 스포크 아이콘과 여섯 Dock 아이콘 배경, 범주별 설정과 단축키
- `forkarak` / `fkk` CLI: 프로젝트·파일 열기, `--goto` 위치 이동, 창 재사용·새 창, JSON 자동화

### 설치와 업데이트

```sh
/bin/bash -o pipefail -c 'curl -fsSL https://github.com/dave915/Forkarak/releases/latest/download/install.sh | /bin/bash'
```

앱은 `~/Applications/Forkarak.app`, 명령은 `~/.local/bin/forkarak`과 `~/.local/bin/fkk`에 설치됩니다. `~/.local/bin`이 PATH에 있으면 다음처럼 사용할 수 있습니다.

```sh
fkk .
forkarak src/main.rs
fkk --goto src/main.rs:24:5
```

기존 사용자는 앱의 **설정 → 업데이트 확인** 또는 앱을 종료한 뒤 `forkarak update`로 업데이트할 수 있습니다. Rust, Xcode, Homebrew, GitHub 로그인은 설치에 필요하지 않습니다.

### 지원 범위

- Apple Silicon / macOS 13 이상을 대상으로 배포하며, 자동 빌드·테스트는 macOS 15에서 수행합니다. Intel Mac 및 Windows/Linux 배포는 검증하지 않았습니다.
- 파일 보기는 언어 서버 없이 동작합니다. 분석·가져오기는 명시적으로 허용하며 언어별 의미 기능은 서버 지원 범위를 따릅니다. Kotlin 등 일부 도구는 첫 사용 다운로드가 필요하고 Spring Properties 의미 분석 브리지는 포함하지 않습니다.
- 번들은 ad-hoc 서명이며 Apple Developer ID 공증은 없습니다.
