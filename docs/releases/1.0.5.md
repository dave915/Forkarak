Forkarak **1.0.5**에서는 현재 보고 있는 그래프나 파일 탭에서 Git 작업을 열 수 있습니다. Apple Silicon Mac과 macOS 13 이상을 대상으로 합니다.

### Git 작업과 프로젝트 탭

- Git 보기에서는 그래프 헤더에, 코드 보기에서는 파일 탭 오른쪽에 커밋·페치·풀·푸시·스태시 작업을 모았습니다. 변경 파일 수와 대상 브랜치를 확인할 수 있고, 좁은 창에서는 커밋과 더 보기 메뉴를 사용합니다.
- 프로젝트 탭과 상단 보기 아이콘이 화면 배율에 맞춰 커집니다. 활성 탭에 닫기 버튼이 표시되며, 창을 오가거나 다른 창에서 보기 설정을 저장해도 선택한 배율이 유지됩니다.

### 코드와 변경 검토

- 새 워크트리의 코드 보기에서는 파일 트리 상단에서 워크트리를 전환할 수 있습니다. Git 보기에서는 브랜치와 참조를 사이드바에서 탐색할 수 있습니다.
- 그래프에서 커밋의 diff를 열면 코드 보기와 같은 줄 번호로 변경을 검토할 수 있습니다. 밝은 테마에서 검색 및 사용처 결과의 일치 부분도 더 쉽게 구분할 수 있습니다.
